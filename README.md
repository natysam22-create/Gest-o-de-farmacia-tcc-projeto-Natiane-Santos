# 💊 Sistema de Gestão de Farmácia
## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de um Sistema de Gestão de Farmácia,
elaborado como Trabalho de Conclusão de Curso (TCC).
O objetivo é desenvolver um site voltado para a divulgação de promoções e
ofertas de farmácias em uma região. A proposta é facilitar o acesso dos
consumidores aos produtos e promoções em um único lugar. O site permitirá que
os usuários pesquisem e encontre ofertas de forma rápida e prática podendo
comparar preços e escolher as melhores opções.
## 🎯 Objetivo Geral
Desenvolver um sistema informatizado para auxiliar na administração de uma
farmácia, proporcionando maior organização, controle e eficiência no
gerenciamento das informações e para pesquisa de preços melhores para os
consumidores.
## Funcionalidades do Sistema
O sistema possui as seguintes funcionalidades:
- Cadastro de informações.
- Consulta de registros.
- Atualização de dados.
- Exclusão de registros.
- Autenticação de usuários.
- Geração de relatórios.
- consulta de preços e promoções
- Atendimento personalizado para os clientes.
